## CN2 GIA、CN2 GIA-E、CN2 GT 到底差在哪

CN2 GIA 是中国电信面向中美方向的高端线路，编号 AS4809。搬瓦工公开的线路说明里把中国方向分成几档：AS4134（163 网）最便宜也最堵，资料里给出的晚高峰丢包率能超过 30%；AS4809 的 GT 版本在 2019 年之后拥堵明显，官方自己的说法是"基本和 AS4134 一样堵"；GIA 版本单价可以到 $120/Mbps，是三档里最贵的。

贵出来的钱买的是丢包率的差异，代价也很明确。GIA 线路容量有限，遇到 DDoS 只能把受影响的 IP 做 nullroute，官方对此并不讳言。要抗攻击的站点，这条线本身不是解法。

GIA-E 是搬瓦工在洛杉矶的电商套餐，同样走 AS4809 的 GIA 网络，支持在 11 个机房之间免费迁移，带宽 2.5Gbps 起步。香港、东京、新加坡、大阪那批标"CN2 GIA"的套餐是机房本身接了 GIA，延迟更低，机房锁定不能迁移，价格也高一截。

洛杉矶 USCA_9 机房另有一条电信线路 AS23764（CTGNet），搬瓦工官方说实际表现与 CN2 GIA 基本等同。同一机房部署了 8 条 10Gbps 的 CN2 GIA/CTGNet 链路，去程按运营商分流：电信走 AS4809，移动走 CMIN2（AS58807），联通走 China Unicom Premium（AS10099）。三网各有一条专门路径，这才是溢价的来源，跟 CPU 强弱没关系。

## 七款怎么选：带宽在哪一档跳，内存从哪一档才够

带宽梯度只跳两次：20G 到 80G 都是 2.5Gbps，160G 和 320G 给 5Gbps，640G 与 1280G 才到 10Gbps。如果你的瓶颈在带宽而不是内存，160G 是第一个质变点，月付也正好从 $56.99 涨到 $86.99。

内存比核数更影响建站体验。40G 的 3 核 2GB 跑 WordPress 加 MySQL 够用；80G 的 4 核 4GB 才能比较从容地开缓存插件、并排跑几个站。20G 那 1GB 内存装完面板和数据库就所剩不多，只适合代理、静态页、单文件服务这类用途。

320G 及以上属于企业级。8 核 16GB、8TB 月流量配 5Gbps，跑实时性强的业务更踏实；640G 和 1280G 分别给到 32GB 和 64GB 内存，月付 $289.99 与 $549.99。个人用户买这两档，绝大部分资源是闲置的。

## DC6 值不值得加钱，亚洲节点贵在哪

DC6 位于洛杉矶 China Telecom IDC，三网各走一条优化线路，另有与 Google 等本地运营商的直连 peering，官方给的定位是"最佳整体网络容量与稳定性"。DC9 的公开描述与它高度重叠，同样是 CN2 GIA + CMIN2 + 联通 Premium 三网回程，两个机房的差别在现有资料里讲不清楚。下单时选默认的 DC6，用下来不合适再在面板里迁到 DC9，比反复研究机房编号更省事。

判断标准是怕延迟还是怕丢包。建站、落地页、代理这类用途，晚高峰的丢包比多 150ms 延迟致命得多，DC6 的钱花得值。国内连海外游戏服、远程桌面这类实时业务，才轮到亚洲节点上场。

## 付款、退款和五个容易忽略的限制

支付方式有支付宝、PayPal、信用卡和银联，国内用户用支付宝不需要额外准备。退款政策是 30 天内可申请，按未使用时长比例计算，以购买时的服务条款为准。

下面几条不会写在下单页上，但会影响你用起来顺不顺：

1. **纯自管理。** 搬瓦工不装环境、不排查应用层问题，只保证底层 VPS 和网络。完全不会 Linux 的人，省下的钱会以运维时间的形式还回去。
2. **不抗 DDoS。** 攻击期间官方会 nullroute 受影响 IP，业务直接中断，没有协商空间。
3. **KVM 常规套餐迁到 CN2 机房，流量变成原来的三分之一。** 这条不适用于 GIA-E 本身，但如果你打算买便宜的常规 KVM 再迁过去，账要重新算。
4. **IPv6 是有的。** 每台给 1 个独立 IPv4 加一个 routed /64 子网，面板内可以即时改 rDNS。
5. **SLA 线和 GIA-E 是两条产品。** 同配置 40G，SLA 版年付 $399.99，GIA-E 年付 $299.99，多出的 $100 买的是 AMD 专属核心、99.99% 可用性承诺和每两周免费换一次 IP。只有需要把可用性写进合同、或者 IP 被墙后必须换的业务，这 $100 才花得值；普通建站买 GIA-E 就行。
